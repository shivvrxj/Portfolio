## ✨ Features

### Responsive Design

The website is designed to work across different screen sizes including:

- Mobile
- Tablet
- Laptop
- Desktop

Media queries are used to adjust the layout and styling for smaller screens.

### Flexbox

Flexbox is used for different alignment and layout requirements such as:

- Navigation
- Buttons
- Skills
- Project links
- Other UI elements

### CSS Grid

CSS Grid is used for major page layouts including:

- Hero section
- About section
- Skills section
- Projects section
- Journey / Education section

### Animations & Transitions

CSS transitions and animations are used to provide subtle visual interactions and improve the overall user experience.
